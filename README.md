# Gauntlet I Commodore 64 Game

Remake of c64 game in the browser

[Hosted Game](http://chemik.ct8.pl/gauntlet_c64_game/)

## Controls:
- wsad: movement
- spacebar: fire
- c: magic potion

4 Characters, 6 monsters, many items and levels

Engine written in a way that you can create your own map in json. [Map generator](https://chemik.ct8.pl/gauntlet_map_generator/)
